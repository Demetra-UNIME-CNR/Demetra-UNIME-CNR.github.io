About the dataset

What it contains. Full-range reflectance spectra (400–2500 nm) collected with a FieldSpec 4 spectroradiometer, co-registered with wet-chemistry assays for N, P, K, Ca, Mg, S, and chlorophyll content (SPAD index).

How to use it. Intended for band-selection research, regression model development, and cross-species generalisation studies. Each campaign folder contains raw .asd exports, pre-processed Excel workbooks, and a metadata README.

Citation obligation. All use — including derivative datasets and models trained on this data — requires citation of the primary DEMETRA paper per the terms below.

Data format. Excel workbooks (.xlsx) with a uniform column layout: wavelength columns followed by nutrient target columns, one spectrum per row. Compatible with Python (pandas, spectral) and R.
